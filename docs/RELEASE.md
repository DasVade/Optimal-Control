# Public release

The owner confirmed on October 24, 2026 that course rules impose no restrictions on publishing this project and authorized making the existing repository public. Earlier private/local-only publication notes are superseded by this release; dated experiment conditions and failures remain unchanged.

[Live project page](https://yixiaoliu.me/projects/robotic-motion-planning-optimal-control/) · [Experimental report](ROBOTICS_REPORT.md) · [Reproduction commands](REPRODUCTION.md)

The release retains original coursework attribution, source history, tested implementations, selected figures/animations and small numerical summaries. It adds no experiments and changes no algorithms or measured results. Source ZIPs, environments, local materials, credentials and full generated runs remain excluded. Original Python caches are present only in historical commits; none are in the current index.

The supplied footstep planner and models retain their original credits. `course_sources/hw5/quad_visualizer.py` credits Russ Tedrake's underactuated example; its BSD notice is retained alongside that file. No blanket license is imposed on third-party source files. Dependencies remain installed separately, not vendored.
